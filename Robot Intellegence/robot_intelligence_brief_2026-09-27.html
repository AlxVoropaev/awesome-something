TL;DR

Главный сдвиг за 23–27 сентября: robot intelligence всё заметнее распадается на специализированные уровни, а не сходится к одной монолитной policy. FLUX 3 Action сделал WAM практически доступным как open-weight foundation policy; две свежие работы с coding agents показали, что Claude Code/Codex-подобные системы полезны не только как runtime-agent, но как авторы обобщаемых planners и генераторы supervision для VLA.

Вторая линия — multi-rate physical intelligence. InternW0 и LiMA отделяют медленное prediction/intent от быстрого action refinement, тогда как NowWAM ставит под сомнение саму необходимость future-video target: часть выигрыша WAM может идти от generative denoising prior, а не от явного предсказания будущего.

Третья линия — deployment intelligence вокруг policy: AdaHVLA адаптирует agent harness по опыту робота, Self-Adaptive VLA использует собственные неудачные rollouts для компенсации hardware shift, MemBodied добавляет фиксированную episodic memory, а BEE превращает human corrections в uncertainty-aware constraints. На Hugging Face главный практический релиз — FLUX 3 Action; из данных особенно интересны свежие Unitree G1 whole-body household datasets и multi-embodiment Uranus-Demo-Data.

1. FLUX 3 Action — WAM становится практической open platform

RELEASE · 23 SEP

Black Forest Labs выпустила FLUX 3 Action, 7B open-weight World Action Model. Она совместно денойзит future-video и action tokens: frozen video VAE кодирует изображения, Qwen3-VL-4B кодирует instruction, а единый diffusion transformer предсказывает 32-step action chunk и, при необходимости, будущие frames.

DROID-finetune занял первое место на публичном RoboLab-120 с 42.92% success против 36.8% у Cosmos3-Nano-Policy и 28.0% у π0.5 в опубликованном leaderboard. В отличие от многих WAM papers, релиз сразу включает base weights, DROID и SO-101 checkpoints, LeRobot integration, LoRA path и оптимизированные variants.

Ограничение: model card прямо предупреждает, что policy выдаёт joint targets и не гарантирует velocity/force/workspace constraints; physical safety остаётся отдельным слоем.

Почему это важно. До этого WAM часто было проще обсуждать, чем реально fine-tune'ить. FLUX 3 Action превращает world-action modeling в доступный engineering baseline: теперь можно сравнивать VLA и WAM на собственном embodiment без самостоятельной сборки всего video-action стека.

2. Coding Agents for Generalized TAMP — Astra/Claude пишут planners, которые обобщаются

PAPER · 24 SEP

Работа проверяет Claude Code (Opus 5) и Codex с GPT-5.6 Sol и GPT-6 Astra не как online robot controller, а как program synthesizer для generalized task-and-motion planning. Агент получает task description и simulator access, сам экспериментирует со средой, пишет программу, а затем программа замораживается и тестируется на unseen instances.

На 28 simulated environments из KinDER и PDDLStream авторы оценили 980 сгенерированных программ на 100 held-out instances каждая — 98,000 episodes. На 16 средах, где доступен hand-engineered planner, coding-agent programs показывают mean success от 56% до 95% против 47% у planners; при росте object count они также требуют примерно на порядок меньше per-instance compute в среднем.

Почему это важно. Это сильный аргумент, что frontier coding model может переносить computation из runtime в design time: один раз экспериментировать, написать reusable planner и дальше исполнять обычный код. Для robot intelligence это потенциально дешёвый System-2 слой над learned low-level skills — особенно там, где задачи меняются комбинаторно, а dynamics достаточно моделируемы.

3. EmbodiedSWE — coding agent как автоматический robotics engineer и data engine

PAPER + CODE · 23 SEP

EmbodiedSWE строит agent-native benchmark для long-horizon dexterous robotics: 6 task suites, 28 tasks, 17 embodiments и горизонты до примерно 30 минут. Coding agent взаимодействует с simulator, пишет и отлаживает solution, а затем EmbodiedSWE-GEN расширяет одну verified solution в большой набор разнообразных trajectories для обучения VLA.

Ключевой результат не в том, что agent умеет решить конкретный simulation task, а в том, что его programmatic solution становится supervision: авторы показывают рост VLA performance при увеличении числа generated demonstrations и real-robot completion после fine-tuning только на coding-agent-generated simulation data.

Почему это важно. Это соединяет две ранее раздельные ветки: agentic coding и robot imitation learning. Вместо дорогостоящего ручного teleoperation coding agent может сначала найти корректную процедуру в simulator, а затем автоматически размножить её в data distribution, пригодную для быстрой neural policy в runtime.

4. InternW0 — world model не должен тормозить action loop

PAPER · 23 SEP

InternW0 разделяет computation на high-capacity video expert и lightweight action expert. Video pathway строит более длинный predictive context, а action expert обновляется быстрее; layerwise K/V переиспользуются и адаптируются к новым observations через context routing, вместо полной video regeneration на каждом motor update.

Training mixture — около 7,200 часов heterogeneous robot и egocentric data. Project page сообщает 98.6% LIBERO average, 93.12% RoboTwin 2.0-Full и 16.47 Hz model-side policy updates; contact-aware post-training добавляет force/tactile channels для contact-rich задач.

Почему это важно. Это решает один из фундаментальных конфликтов WAM: богатое prediction дорого, а физическая обратная связь должна быть быстрой. Asynchronous architecture позволяет оставить predictive world context в системе, не заставляя motor control ждать новый video rollout.

5. NowWAM — future prediction может быть не причиной успеха WAM

PAPER · 23 SEP

NowWAM убирает отдельный future-image target. Во время training current observation зашумляется по diffusion trajectory, а одна и та же visual stream одновременно учится denoising и action prediction. В inference policy получает clean current observation — без visual rollout.

Контролируемый ablation особенно показателен: future target t+32 даёт 83.70%, а past target t−16 — 83.80%; clean-only adaptation заметно хуже. На LIBERO-Plus NowWAM достигает 87.7% с FLUX2-Klein, использует вдвое меньше visual tokens и сокращает training step time с 2.85 до 1.63 s. Text-to-image Z-Image backbone также достигает 87.8%.

Почему это важно. Работа меняет causal story вокруг WAM. Если benefit приходит в большой степени из generative denoising representation, а не из явного foresight, то часть робот-систем можно сделать значительно проще и дешевле — оставив generative prior, но не оплачивая future-video generation.

6. LiMA — slow imagination + fast dexterous reaction

PAPER · 23 SEP

LiMA строит asynchronous dual-system для bimanual dexterity. Slow Future Dreamer генерирует sparse long-horizon intent, а fast Motion Refiner обновляет dense actions по свежим observations. Latent Schrödinger Bridge Coupling связывает редкие intention updates с высокой action frequency.

На шести real-world bimanual tasks авторы сообщают 70.8% overall task success и 78.9% average subtask success; amortized inference latency на 32-step chunk — 325 ms против 600 ms у Cosmos-Policy в их H100 comparison.

Почему это важно. В dexterous manipulation особенно опасно держать high-level reasoning и contact reaction на одной частоте: пальцы могут потерять объект быстрее, чем большая generative model пересчитает план. LiMA показывает практически пригодную архитектуру, где slow world imagination задаёт intent, а fast subsystem сохраняет физическую реактивность.

7. AdaHVLA — harness вокруг VLA становится обучаемым

PAPER · 24 SEP

AdaHVLA атакует long-horizon failure не изменением самой VLA, а адаптацией code-based coordination harness, который хранит task history, progress и orchestration logic. Evidence analysis, harness revision и behavioral assessment разделены на разные agent contexts; revision graph связывает hypotheses, изменения и observed effects.

На NaVILA-LH mean test success растёт с 22.5% до 57.5%; на manipulation tests улучшение достигает 30.8 percentage points поверх initial harness для трёх VLA backbones. Авторы также показывают real-world deployment.

Почему это важно. Это переносит важную идею из software agents в robotics: качество системы определяется не только foundation model, но и stateful harness вокруг неё. Такой harness можно улучшать быстрее и дешевле, чем переобучать VLA, а значит orchestration/memory/recovery становятся самостоятельным объектом обучения.

8. Self-Adaptive VLA — robot использует собственные ошибки как calibration context

PAPER · 24 SEP

Self-Adaptive VLA предназначена для hardware shifts: actuation bias, encoder offsets и изменения workstation. Lightweight context encoder сжимает прошлые visual observations, proprioception и actions в latent context token, который через AdaLN модулирует policy; несколько context tokens можно ensemble'ить для iterative correction.

На четырёх precision-critical bimanual/dexterous tasks система восстанавливает более 80% performance базовой policy под hardware shifts. На project demo перенос со Station 1 на Station 2 даёт 0/5 для base policy, 2/5 после одного failed trial в context и 5/5 после двух.

Почему это важно. Fleet robotics ломается не только на новых задачах, но и на медленном дрейфе железа. Если robot может сам оценить собственные failed rollouts и компенсировать bias без полного retraining/recalibration, резко снижается эксплуатационная стоимость deployment на сотнях устройств.

9. MemBodied — episodic memory без бесконечного visual context

PAPER + CODE · 23 SEP

MemBodied добавляет fixed-size episodic memory из двух частей: associative state, обновляемый между policy calls, и episode anchor, сохраняющий компактное представление initial scene. Policy больше не обязана каждый раз получать всю историю кадров.

На пяти RMBench memory tasks система достигает 7.81× mean success относительно stateless policy и 2.98× относительно vanilla recurrent memory; strongest memory baseline она превосходит в 1.3× при 10× меньшем числе дополнительных parameters. На fully observable LIBERO-Long результат — 90.6%, +5.4 points к stateless π0.

Почему это важно. Long-horizon household tasks требуют помнить исчезнувшие из поля зрения объекты, уже выполненные этапы и раннее состояние сцены. Fixed memory делает это без квадратично растущего multimodal context, то есть приближает persistent robot memory к production latency.

10. BEE — human intervention как constraint для real-world RL

PAPER · 23 SEP

BEE рассматривает human correction не как action, который надо копировать, а как evidence о допустимом изменении policy. Correction Model предсказывает correction и её consistency по каждой action dimension; стабильные corrections задают tight constraint, а вариативные позволяют policy исследовать и превзойти expert imitation.

На трёх real-world manipulation tasks и LIBERO-Pro при matched online-data budget authors сообщают 91.2% average success против 57.5% у RLT и 42.1% у DSRL, одновременно снижая intervention rate на real tasks.

Почему это важно. В real-robot RL человеческое внимание — один из самых дорогих ресурсов. BEE позволяет использовать каждое вмешательство не как единичный label, а как локальную геометрию safety/skill constraint, что потенциально масштабирует post-training на реальные роботы значительно лучше обычного DAgger-style cloning.

11. Efficient VLA deployment — compute тоже становится adaptive

PAPER · 24 SEP

Decoupled Early Exits рассматривает flow-matching VLA как три независимые compute axes: depth VLM backbone (V), depth action expert (A) и число denoising steps (D). Lightweight Exit Transformers позволяют останавливать backbone и action expert на разных глубинах; KV-cache synthesis заполняет пропущенные backbone states.

На SmolVLA и π0.5 в LIBERO/Meta-World joint configurations сокращают latency на 79.2% и FLOPs на 31.8%, при этом mean success в их experiments растёт на 5.6%.

Почему это важно. Robot task difficulty неодинакова: удерживать уже схваченный объект и интерпретировать сложную новую сцену не должны стоить одинаковое количество compute. Task-dependent inference budget — важный шаг к on-device foundation policies, где power и latency ограничены жёстче, чем в cloud LLM.

Agentic robotics: два разных пути уже хорошо различимы

Agent → reusable program

Generalized TAMP: coding agent исследует simulator, пишет planner/controller, после чего LLM можно убрать из runtime.

Agent → training data

EmbodiedSWE: coding agent находит verified solution, а система превращает её в demonstrations для neural VLA.

Почему это важно. Это более зрелая постановка, чем «давайте GPT напрямую крутить motor API». Frontier model может тратить много compute там, где это допустимо — во время engineering/training — а production robot затем исполняет компактный deterministic program или learned policy с низкой latency.

🤗 HF radar — 23–27 сентября

1. FLUX 3 Action collection

На HF WAM trending свежая линейка Black Forest Labs занимает верхние позиции: base model, SO-101 и DROID. На момент проверки SO-101 показывает примерно 487 monthly downloads / 34 likes, DROID — около 344 / 23; base набрал около 88 likes. Почему это важно. Это не просто checkpoint: наличие embodiment-specific heads, SO-101 recipe и DROID variants резко снижает barrier-to-entry для экспериментов «WAM vs VLA» на собственном железе.

2. Unitree G1 whole-body household datasets

Unitree за последние сутки обновила большой пакет G1 WBT datasets: dishwasher loading, tidying living room, cushions, clothes, laundry, supermarket shelf organizing и другие tasks для Inspire/BrainCo hands. Эти datasets содержат full robot configuration, EEF targets и hand commands; уже существующие WBT entries показывают сотни episodes на задачу и LeRobot-compatible structure.

Почему это важно. Дефицит humanoid data сегодня — не в ещё одном tabletop grasp, а в whole-body household trajectories, где locomotion, waist, bimanual reach и dexterous hand control связаны в одну последовательность. Такой corpus нужен для post-training humanoid VLA/WAM и для честных исследований locomotion-manipulation integration.

3. D-Robotics Uranus-Demo-Data

Свежо обновлённый dataset содержит около 1,550 samples / 12.1 GB и готовые примеры для разных embodiments, включая ALOHA, ARX5, UR5, Franka, G1, DOS-W1 и X5. Каждый sample упакован как self-contained environment: MJCF/XML, calibrated cameras, qpos trajectory, reference images и ground-truth video. HF показывает около 1.5k downloads за месяц.

Почему это важно. Это закрывает другой дефицит: не масштаб demonstrations, а sim-ready, geometry-aware cross-embodiment packaging. Такой формат особенно полезен для world models, video/action prediction и cross-embodiment evaluation, потому что содержит одновременно визуальную и кинематическую структуру среды.

4. EasyWAM collection

OpenMOSS обновил серию EasyWAM checkpoints на Wan2.2 и Cosmos-Predict2.5: Unified, Hidden и Mixture-of-Transformers variants, включая joint video-action и IDM-style architectures. Adoption пока маленький — это скорее свежая research matrix, чем popularity leader.

Почему это важно. EasyWAM полезен как controlled architecture lab: можно сравнивать несколько способов связать video DiT и action DiT на близких backbones и training protocol. Для поля это важнее, чем ещё один единичный SOTA checkpoint, потому что помогает понять, какая именно связка world/action modeling работает.

EasyWAM collection

5. PhysBrain 1.5-8B — HF update внутри окна

PhysBrain 1.5-8B обновлялся в пределах текущего HF-окна и остаётся заметным robotics/any-to-any объектом. Model объединяет embodied understanding, discrete action tokens и future-state prediction в одном autoregressive Qwen3-VL-derived backbone; доступен обычный Transformers interface и demo Space.

Почему это важно. В отличие от specialist VLA/WAM, PhysBrain проверяет идею общего token space для reasoning, action и future state. Даже если closed-loop robot evidence пока слабее его understanding benchmarks, это удобный open baseline для исследований «один physical foundation model vs modular stack».

6. Light-O1-Preview — продолжающийся HF signal

Underlying research вышел чуть раньше строгого paper-окна, но checkpoint обновлялся в последние 5 дней и продолжает набирать usage: около 375 monthly downloads / 19 likes на момент проверки. Это text→reasoning→whole-body action-token preview, а не полноценная visual humanoid policy.

Почему это важно. Его value — в shared whole-body action vocabulary и human-action pretraining thesis. Это полезный экспериментальный объект для вопроса, можно ли построить transferable motion prior, который затем retarget'ится на разные humanoid embodiments.

5 главных выводов периода

  1. Agentic robotics взрослеет: coding agents полезнее всего выглядят либо как authors of reusable planners, либо как generators of training data — не обязательно как медленный runtime-controller.
  2. WAM перестаёт означать «обязательно генерируй будущее видео»: FLUX делает классический WAM практичным, но NowWAM показывает, что часть выигрыша можно получить без future target.
  3. Multi-rate architecture становится общим паттерном: expensive predictive/semantic layer и fast reactive action layer естественно работают на разных частотах.
  4. Deployment intelligence выходит за пределы policy weights: memory, harness, hardware-shift adaptation и human constraints становятся самостоятельными first-class components.
  5. Данные для humanoids становятся содержательнее: свежие G1 WBT datasets смещают open data от isolated manipulation к household whole-body sequences.

Что читать / пробовать полностью

  1. FLUX 3 Action — как самый практичный новый WAM baseline.
  2. Coding Agents for Generalized TAMP — лучший свежий evidence для reusable agent-written robot programs.
  3. EmbodiedSWE — как мост coding agent → VLA data engine.
  4. InternW0 и LiMA — два варианта slow/fast predictive-action architecture.
  5. NowWAM — потому что он меняет саму интерпретацию, зачем generative backbone помогает control.
  6. Self-Adaptive VLA и MemBodied — если интересует production deployment, а не только benchmark success.

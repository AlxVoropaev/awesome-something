PEAR обучает модель рассуждения управлять руками через RL

16 ноября · публичный выпуск arXiv и открытые артефакты

Авторы дообучили Qwen3.8‑27B с помощью RL в LIBERO и на двух задачах RoboDojo. Модель видит камеры и состояние рук, запоминает ход эпизода и выдаёт следующую позу захвата. Обратную кинематику и движение исполняют обычные контроллеры. Для обучения не записывали роботные демонстрации. Оценка идёт раундами, физические прогоны ограничены 25 решениями с учётом повторов при недостижимой позе.

На LIBERO вариант после этой стадии набрал 74,4% против 1,6% у базы на 2 000 эпизодах. Финальная модель завершила 18 из 30 попыток на физическом двуручном YAM, база — 0 из 30, модель после одного LIBERO — 7 из 30. Опыт охватывает поднятие предметов и выравнивание блоков. Эти два типа задач встречались в RoboDojo, а сама физическая платформа была новой. Результат по LIBERO-Pro для новой задачи в знакомой сцене — 57,4%, сравнение с π0.5 опирается на опубликованный результат другого коллектива.

Почему это важно. Часть навыка работы с интерфейсом робота можно получить через симуляционную обратную связь вместо телоуправления. Раздельные чекпоинты дают возможность измерить вклад переноса и дополнительной практики на близких задачах.

Agentic-Teacher пишет программы, которые исправляют данные для VLA

16 ноября · публичный выпуск arXiv

GPT‑5.6 Sol сравнивает удачные и неудачные прогоны π0, выбирает состояние для вмешательства и пишет программу продолжения через инструменты среды. Из проверенных программ получают траектории ремонта. Их разнообразят временно согласованным шумом, убирают лишние кадры покоя и фильтруют по ошибке flow matching замороженной базовой модели. После обучения обновлённая VLA исполняет задачи самостоятельно.

На LIBERO‑10 успех вырос с 79,4% до 87,8%, а дообучение только на собственных успехах VLA дало 81,4%. На MetaWorld‑10 получены 90,6% против 80,4% у базы и 85,2% у такого дообучения. Для каждой задачи оценивали по 50 начальных состояний, одинаковых для вариантов и отдельных от сбора ремонта. Все эксперименты симуляционные.

Почему это важно. Удачный код сам по себе ещё не создаёт хороший обучающий пример. Связь между конкретным отказом VLA, начальным состоянием ремонта и фильтром пригодности траектории даёт проверяемый способ собирать трудные примеры.

Objectives as Policies поручает модели составлять цели для MPC

16 ноября · публичный выпуск arXiv

VLM составляет программу из этапов, критериев перехода и членов стоимости из фиксированной библиотеки. Кандидат проверяется в цифровом двойнике, ошибки дают обратную связь для правки программы. При запуске программу фиксируют. Контроллер MPC сам определяет команды по текущему состоянию и контактной модели.

На четырёх задачах для каждой отобрали по пять программ, уже успешных в симуляции, и один раз запустили каждую в двух физических конфигурациях с изменённым положением предметов. Получено 32 успеха из 40. Часть отказов связана с проскальзыванием и расхождением жёсткости предметов, которые в модели считаются жёсткими.

Почему это важно. Программу стоимости можно проверять и править отдельно от исполнительного контура. Результат показывает, почему качество двойника определяет перенос даже после того, как модель правильно описала задачу.

ESI учит VLA продолжать работу после вмешательства агента

16 ноября · публичный выпуск arXiv

В симуляции двуручного ARX X5 GPT‑6 Astra задаёт подзадачу, просматривает действия π0.5 и при необходимости вмешивается через инструменты управления. В обучение идут удачные действия и продолжения после исправлений. Веса LLM остаются замороженными. Система после обновления снова использует и LLM, и VLA.

На десяти отобранных задачах RoboDojo у связки средняя по задачам доля полного успеха выросла с 29,68% до 49,41%, балл с частичным зачётом — с 45,67 до 62,03. Сравнение планировалось на 200 случаях с одинаковыми сценами. В парной разбивке указаны 197 случаев, из них 41 завершили обе системы. На этих 41 среднее число вмешательств с исполнением упало с 10,85 до 4,71 на эпизод.

Почему это важно. Полезное продолжение после поправки даёт сигнал для обучения даже тогда, когда эпизод целиком не завершён. Сопоставление числа вмешательств важно для понимания стоимости гибридной схемы.

X-Nav ведёт гуманоида из здания на улицу

16 ноября · публичный технический отчёт

У MELIOR два выхода по RGB. MELIOR‑A прогнозирует относительные команды движения, MELIOR‑N предлагает цель навигации для следующего шага. X‑Navarch дробит поручение, обновляет подцели и проверяет прибытие. При исполнении целей работают слой объезда препятствий, LiDAR, одометрия и отдельный контроллер ходьбы.

Авторы описали два прогона Lingxi X2 по одному маршруту до соседнего здания. Прямой вариант прошёл 96,6 м за 3 мин 24 с, включая ожидание транспорта. PROOF учит локомоцию обходиться без испорченной глубины

16 ноября · публичный выпуск arXiv

Учитель в симуляции получает карту высот, которую иногда скрывают, чтобы выучить ходьбу по проприоцепции. Студент оценивает неопределённость признаков камеры глубины. При сильном сбое признаки подавляются, управление опирается на состояние тела.

В симуляции при сильных искажениях на подъёме по лестнице успешны 95 из 100 попыток против 73 из 100 у студента без оценки неопределённости и фильтра, но с тем же маскированным учителем. На Go2 с RealSense D435 испытаны калиброванные ухудшения глубины на ровном полу и лестнице. Чистые физические паркур-тесты с прыжком и подъёмом на платформу проведены отдельно.

Почему это важно. Если при потере видимости всегда подавать шум в политику, контроллер может уверенно ошибаться. Отдельная стратегия ходьбы по проприоцепции даёт осмысленное поведение вблизи отказа сенсора.

Вердикт. Начать с тестов окклюзии и восстановления глубины на своём рельефе. Отдельно проверить препятствия, которые без зрения нельзя надёжно преодолеть.

TouchTwin переносит измеренный контакт в генерацию данных

16 ноября · публичный выпуск arXiv

Перчатка записывает контакт и нормальное усилие вместе с эгоцентрическими кадрами. Coding agent восстанавливает взаимодействие в MuJoCo. Проверенные повторы варьируют хват, скорость, массу и трение. Генератор видео меняет вид сцены поверх симуляции, разметка силы наследуется от физического повтора.

На отложенных записях захвата кружки доля пропущенных кадров контакта у классификатора снизилась с 32,2% до 13,1% при обучении на повторах с измеренным контактом. В отдельной оценке политики на 36 симуляционных повторах успешны 35 против 33 у реконструкции только по видео и 26 у обучения по исходной позе.

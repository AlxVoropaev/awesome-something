Самый интересный agentic robotics результат — EmbodiedSWE: coding agents пишут и отлаживают task-specific robot programs в simulation, после чего verified solution автоматически превращается в сотни разнообразных demonstrations для VLA. Coding agent здесь выступает не runtime-controller, а автоматическим robotics engineer / data generator.

Параллельно сразу несколько работ подтверждают архитектуру slow predictive intelligence + fast reactive execution: InternW0 кэширует video-world context и чаще обновляет action; LiMA разделяет Future Dreamer и Motion Refiner; PredActor объединяет future-state prediction с direct humanoid action control на 50 Hz. А NowWAM показывает важную границу: future-image prediction не всегда нужна вообще — иногда достаточно generative denoising prior текущего observation.

1. FLUX 3 Action — главный релиз окна

NEW RELEASE · 23 SEP

Black Forest Labs выпустила FLUX 3 Action — open-weight 7B World Action Model. Модель получает camera frames, robot state и text instruction, после чего совместно денойзит future video tokens и action tokens в одной diffusion sequence.

camera frames + robot state + instruction ↓ frozen video VAE + frozen Qwen3-VL-4B text encoder ↓ 7B diffusion transformer ↙ ↘ future video tokens action tokens ↓ 32-step action chunk (+ optional decoded future frames)

Для DROID-checkpoint Black Forest Labs сообщает 42.92% success на RoboLab-120. Публичный NVIDIA leaderboard ставит FLUX 3 Action на первое место: Cosmos3-Nano-Policy — 36.8%, π0.5 — 28.0%, DreamZero — 25.7%, GR00T N1.6 — 7.2%.

Практическая часть сильнее обычного research release: опубликованы DROID и SO-101 policies, LeRobot integration, LoRA recipe, step-distilled 1-step variant и FP8 variants. SO-101 policy использует две камеры, 8-observation history, предсказывает 42 actions, исполняет 32 при 30 Hz и затем replans. DROID version выдаёт 32 actions при 15 Hz.

Ограничение: model card прямо предупреждает, что модель выдаёт joint targets и сама не ограничивает velocity, force или workspace; safety layer остаётся обязанностью deployment stack.

2. EmbodiedSWE — coding agent превращается в robotics data factory

NEW PAPER · 23 SEP

EmbodiedSWE — самый важный свежий результат по coding agents в robotics. Frontier coding agent получает simulator, state inspection и control primitives, пишет Python solve(env), запускает его, анализирует failure, переписывает и повторяет до verified solution.

После решения task компонент EmbodiedSWE-GEN превращает одну проверенную программу в большой training set для VLA, варьируя scene, strategy, valid phase starts, dynamics/noise и visuals. Trajectories сохраняются только после task grader и open-loop replay check.

coding agent → write / run / debug solution in simulator → verified task program → scene / strategy / phase / dynamics / visual diversification → hundreds of successful trajectories → fine-tune VLA → deploy learned policy

На 6 задачах SmolVLA улучшается с 18% success при 10 demonstrations до 69% при 400. В held-out variations agent-aided data даёт mean rubric score 0.233 против 0.066 у script-only diversification.

Есть и sim→real test: Opus 5-written lamp-disassembly solution породила 500 sim trajectories, которыми fine-tuned π0.5-DROID без real demonstrations. На Franka policy достигла полного unscrew/extract bulb в 20% из 10 trials; pretrained baseline был 0% на всех milestones.

Сильный conceptual result: coding agent не обязан сидеть в runtime; он может быть автоматизированным инженером, создающим supervision для дешёвой runtime-policy.

3. InternW0 — predict slowly, act quickly

NEW PAPER · 23 SEP

InternW0 — physical world model, который явно разделяет частоты вычисления. High-capacity video expert строит более дальний predictive context, а lightweight action expert обновляет control чаще. Вместо полного rerun video model на каждом action tick система кэширует layerwise K/V и адаптирует context под fresh observation.

slow loop: observation → video/world expert → predictive context + cached K/V fast loop: fresh observation + cached predictive context → lightweight action expert → action update

Training mixture — около 7,200 часов heterogeneous robot + egocentric data, плюс contact-aware post-training с force/tactile channels.

На quantitative pipetting с 20-DoF dexterous hand + 7-DoF arm reported progress: 65.3% против 46.7% у π0.5 и 18.7% у Fast-WAM. Авторы отдельно исключают video generation из action critical-path measurement.

Принцип очень важен для humanoids: world prediction не обязана обновляться на той же частоте, что и motor decision.

4. NowWAM — а future prediction вообще нужна?

NEW PAPER · 23 SEP

Beyond Future Prediction: Denoising as Generative Adaptation for Robot Control задаёт неудобный для WAM field вопрос: может быть, преимущество generative backbone связано не с foresight, а с тем, что diffusion denoising формирует сильное visual representation?

В NowWAM отдельного future target нет. На training текущий observation зашумляется на случайном diffusion timestep; один noisy stream используется одновременно для visual denoising loss и action prediction. На inference — clean current observation, без visual rollout.

Ключевой ablation: future target t+32 даёт 83.70%, а past target t−16 — 83.80% на контролируемом subset. Headline на LIBERO-Plus: 87.7% с FLUX2-Klein против 81.6% у future-target ImageWAM; с Z-Image backbone — 87.8%. Training uses 392 visual tokens вместо 784, step time 2.85 → 1.63 s.

Вывод: «WAM лучше VLA, потому что представляет будущее» становится слишком простой историей. Generative prior может быть полезен как robust representation learner даже без foresight.

5. LiMA — long-term imagination + fast dexterous reaction

NEW PAPER · 23 SEP

LiMA переносит multi-rate idea в bimanual dexterity. Slow Future Dreamer, инициализированный от Cosmos-Predict2-2B, генерирует future visual latents и coarse macro-action intent; быстрый Motion Refiner использует последние observations и уточняет dense actions. Между ними — Latent Schrödinger Bridge Coupling.

На 6 real-world bimanual tasks reported full-task success — 70.8%, average subtask success — 78.9%. Amortized latency на 32-step chunk — 325 ms против 600 ms у Cosmos-Policy в авторском H100 comparison; Dreamer обновляется раз в четыре Refiner updates.

Архитектурно это тот же общий принцип, что InternW0: slow intent/imagination не должно блокировать fast physical correction.

6. BEE — human corrections как constraint, а не label

NEW PAPER · 23 SEP

В BEE Correction Model оценивает, как человек исправил бы VLA proposal и насколько correction стабилен по каждой action dimension. Если correction стабилен — RL policy жёстко держится рядом с human constraint; если сильно варьируется — constraint ослабляется и policy может улучшать expert behavior.

На 3 real tasks + LIBERO-Pro authors report 91.2% average success против 57.5% у RLT и 42.1% у DSRL, одновременно с минимальным intervention rate на real tasks.

Практически важная интерпретация: human intervention — не обязательно «правильный action», а evidence о допустимой области policy.

7. MemBodied — память VLA без раздувания context

NEW PAPER · 23 SEP

MemBodied добавляет fixed-size episodic memory к VLA. Вместо concatenation всех прошлых images policy получает два compact components: associative state, обновляемый между calls, и episode anchor, сохраняющий компактное представление начальной сцены.

На пяти RMBench memory tasks MemBodied показывает 7.81× mean success относительно stateless policy, 2.98× относительно vanilla recurrent memory и 1.3× относительно strongest memory-augmented baseline при 10× меньшем числе добавленных parameters. На LIBERO-Long — 90.6%, +5.4 pp к stateless π0.

8. PredActor — predictive humanoid controller, который влезает в onboard 50 Hz

NEW PAPER · 21 SEP

PredActor для Unitree G1 совместно diffusion-предсказывает future physical states и executable actions. В отличие от generator→tracker architectures, predicted state используется как внутреннее steerable representation, а actions идут непосредственно в controller.

Policy получает proprioception history + optional task context, выдаёт 29 joint-controller commands и предсказывает future state horizon. CFG используется для text behavior, classifier guidance — для steering predicted state trajectory к destination/body objectives.

После rolling-DDIM и runtime optimization полный callback на Jetson Orin NX составляет 16.79 ms median / 19.38 ms p95 при 20 ms control period; 593 из 600 callbacks уложились в 20 ms. Hardware eval пока в основном demonstrative, но это сильный signal, что predictive latent может жить непосредственно в fast humanoid controller.

Agentic robotics / frontier-model watch

В текущем 5-дневном окне не найден новый независимый real-robot тест типа «GPT/Claude/Gemini напрямую получает camera + robot API» масштаба недавних Robocurve/VIA экспериментов.

Зато EmbodiedSWE даёт более зрелый вариант использования frontier coding agents: модель может автономно искать solution в simulator, писать control code, валидировать его и затем превращать найденное решение в training supervision для VLA. Для industrial robotics это потенциально практичнее, чем держать Claude/Codex в control loop.

5 главных выводов периода

  1. WAM превращается из архитектурной идеи в usable open stack. FLUX 3 Action даёт weights, LeRobot, task LoRA, DROID/SO-101 policies и сильный RoboLab result.
  2. Но “world model = future video” уже не выглядит обязательным. NowWAM показывает, что generative denoising prior сам по себе может дать robustness; distillation-work показывает, что WM может вообще исчезнуть из deployment.
  3. Главная системная архитектура сейчас — multi-rate. Большой predictive/reasoning layer обновляется редко, маленький action layer быстро реагирует на fresh observation. InternW0 и LiMA дают два независимых варианта.
  4. Coding agents начинают приносить максимум пользы не как robot pilot, а как automated robotics engineer. EmbodiedSWE: agentic code search → verified solution → generated demonstrations → learned VLA.
  5. Память и human feedback становятся first-class modules. MemBodied показывает fixed episodic memory, BEE — uncertainty-aware human constraints. Generalist policy всё меньше похожа на единственный монолит.
